# CKO CORE

Núcleo técnico versionável do CKO.

## Baseline vigente

- CKO CORE SDK `1.0.0`;
- camada semântica homologada pelas SPR-010–017;
- API pública com 646 exports raiz, únicos e resolvidos;
- 610 exports anteriores preservados e 36 exports adicionados pela SPR-017;
- arquitetura, código, testes, scripts, configurações e documentação técnica mantidos neste repositório.

A SPR-017 está tecnicamente homologada. A SPR-018 permanece sem escopo ou autorização oficial. A CKO-RFC-001, localizada no repositório pai, continua como proposta não autorizada e não define a SPR-018.

Consulte `ARCH-001_CKO_CORE_MASTER_ARCHITECTURE_v1.2.md`, `CKO_CORE_V1_PUBLIC_API_CATALOG.md`, `SPR017_HOMOLOGATION_REPORT.md` e `ROADMAP.md`.
