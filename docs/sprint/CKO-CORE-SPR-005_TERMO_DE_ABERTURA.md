# CKO-CORE-SPR-005 — Termo de Abertura

## Objetivo

Consolidar a fundação arquitetural do CORE por evolução incremental da estrutura existente.

## Entregas

- contratos internos;
- modelos documentais;
- fronteiras de serviços e API;
- Baseline arquitetural;
- ADRs;
- testes estruturais;
- integração de validação com VS Code.

## Fora do escopo

- alteração do scanner;
- alteração de bancos;
- OCR;
- embeddings;
- RAG;
- agentes;
- Dashboard;
- movimentação, renomeação ou exclusão de documentos.
